# Aurelia Dental

Premium bilingual dental clinic website built with React, Vite and React Router. The project includes treatment, doctor and booking pages, responsive navigation, and a client-side appointment demo.

## Development

```bash
npm ci
npm run dev
```

## Production

```bash
npm run lint
npm run build
```

The GitHub Actions workflow deploys `dist` to GitHub Pages. Hash-based routing keeps nested pages available after refresh.
